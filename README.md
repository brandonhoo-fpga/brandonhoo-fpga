## Brandon Hoo

Computer Engineering senior at NJIT, graduating May 2026.

I build FPGA hardware. The pinned repos are self-driven projects in Verilog and SystemVerilog targeting the Lattice iCE40 (Nandland Go Board) and the Cyclone IV EP4CE115 (Terasic DE2-115). They cover real-time graphics, multi-FSM gameplay, embedded protocols, and a hardware perceptron.

### Featured Projects
- **[Pipelined Mandelbrot Set Visualizer](https://github.com/brandonhoo-fpga/fpga-mandelbrot-set)** — 64-stage pipelined fractal renderer in Verilog, producing one pixel per clock at 25 MHz with 8-bit color over VGA on the DE2-115. Originally built on the Go Board before porting to the DE2-115 to gain DSP and color depth.
- **[Morse Code Decoder & UART Transmitter](https://github.com/brandonhoo-fpga/fpga-morse-code-fsm)** — Hardware FSM that decodes manual Morse input in real time and transmits decoded ASCII to a PC over UART.
- **[FPGA Pong Game](https://github.com/brandonhoo-fpga/fpga-pong-game)** — Two-player Pong with VGA video, multi-FSM coordination, paddle-section bounce angles, and LFSR-randomized serve direction on the Lattice iCE40 Go Board.
